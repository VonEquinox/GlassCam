## 推荐决策与执行批次（供参考）

1. **第一批（低风险高收益：止血 + 修 Bug + 清理残余 UI）**
   - `B1` 默认关闭日常 `Balanced` 的 ~570MB 调色前归档，增加归档开关与空间清理
   - `B2` 修复 `Reset effect adjustments` 覆盖 HNCS / FFCS / LUMIX 三引擎
   - `B3` 将 `RAW recording` 测试采样卡片移入 `Advanced`
   - `C1` 移除点不动的 `24 MP` 假按钮、顶栏 `GLASSCAM` 铭牌和永久灰死的变焦栏

2. **第二批（塑造「一块玻璃」的核心视觉体验）**
   - `G1` 整板镂空外围玻璃 + 0.5pt 光学倒角切边（取代四块拼缝与四个白折角）
   - `G2` 光学蚀刻排版语言（精简外围遮挡，最大化透出广角视差）
   - `G3` 半透棱镜玻璃快门 + 圆环流光进度弧（取代实心大白饼与系统菊花）
   - `G4` 底部横向光学滤镜拨盘（边看取景边盲切胶片风格，配合刻度触感）
   - `G5` 设置与状态卡片改为不断流的半透玻璃浮层（消除纯黑背景跳出感）

3. **第三批（补齐真机手持拍摄手感）**
   - `A2` + `A3` 快门/四帧完成触觉反馈（Haptics）+ 物理音量键 / Camera Control 快门
   - `A4` 物理重力方向感知（修复竖屏锁定下横拍成片歪倒）
   - `A1` 点按对焦 / 测光与前期相机曝光补偿（EV）
   - `G6` + `C4` 灯箱式玻璃回看页（下拉返回、底部胶片打孔式参数展示、跨启动保留最近一张）
   - `C2` + `C5` 实时色彩准入状态就地说明、底层报错本地化清理
   - `A5`（可选大项）评估是否将单张阻塞式工作流放宽为「采集完即允许下一张快门、后台排队处理」
