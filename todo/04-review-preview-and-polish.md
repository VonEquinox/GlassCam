# 04 · 灯箱式成片回看、实时色彩提示与细节打磨

让拍完照片后的检查与分享同样具有「玻璃干版在灯箱上审片」的质感，并消除预览与多语言中的割裂细节。

---

## [G6 & C4] 灯箱式玻璃回看页（CaptureReview）体验升级

### 现状问题
- 打开缩略图时先展示 `160px` 长边的极糊缩略图，等后台解码完才突变为 `2048px`，跳变生硬；且 24MP 照片放大到 `5×` 时 `2048px` 依然偏软。
- 全屏纯黑 `NavigationStack` 搭配系统标准导航栏，只能点击左上角 `Camera` 返回，不支持直觉的下拉关闭手势。
- 底部只显示有效像素估计和白平衡，缺少摄影用户最关心的**色彩风格名称、拍摄模式（Balanced / Speed）、快门速度、ISO、光圈**。
- `workflow.latest` 只驻留在内存中，杀掉 App 或系统回收后重开，左下角缩略图即变空。

### 打算怎么做
1. **灯箱悬浮视觉与下拉手势返回**：
   - 移除系统 `NavigationStack` 顶栏，改为悬浮在暗调磨砂玻璃背景上的极简顶/底透明玻璃胶囊（左上关闭、右上分享）。
   - 当缩放倍率为 `1×` 时，支持单指下拉拖拽缩小并平滑关闭回看页返回实时取景（Interactive Pull-to-Dismiss）。
   - 使用 SwiftUI `matchedTransitionSource` / `navigationTransition(.zoom)` 让照片从左下角玻璃小窗自然放大展开。
2. **底片片基式拍摄参数栏（Film Edge Metadata）**：
   - 在底部以等宽精致小字展示完整拍摄铭文，例如：
     - 第一行：`FFCS · PROVIA  |  Balanced · 4 RAW`
     - 第二行：`24mm  f/1.78  1/120s  ISO 80  ·  24MP HDR`
   - 点击底部参数栏可展开查看详细的白平衡色温与分辨率信息。
3. **预览清晰度与加载过渡优化**：
   - 将常驻预览长边从 `160px` 提升至 `384px`（内存占用仅约 2.3MB Float32，彻底消除刚点开时的马赛克感），全尺寸回看解码上限提升至 `4096px` 以支撑 `5×` 放大检视细节，解码完成时加入 0.15 秒柔和清晰度过渡。
4. **跨启动保留最近一张回看成片**：
   - 将最近一次确认保存的成片副本保留在 `Application Support/GlassCam/LatestReview/`（单张覆盖更新，排除备份），启动时异步恢复左下角缩略图，随时可回看上一张成片。

## [C2] 实验实时色彩（Live Color）准入状态的就地透明提示

### 现状问题
- 默认色彩引擎为 `HNCS`，用户在高级设置打开 `Experimental live color` 后回到相机看不到任何色彩变化（`LiveColorRecipe` 仅放行 `FFCS + XH2S + PROVIA/ACROS + 0 EV + 无参考调整`），回退原因藏在二级状态弹窗中，像开关坏了一样。

### 打算怎么做
1. **设置开关处即时告知**：
   - 在 `Experimental live color` 开关下方动态显示当前所选配方是否支持实时色彩：若当前处于不支持的组合（如 HNCS 或 LUMIX），直接以温和的副文案写明原因及支持范围（避免用户切回取景器空等）。
2. **滤镜拨盘标记**：
   - 开启实时色彩开关时，在底部滤镜拨盘中为支持实时预览的风格（如 `PROVIA`、`ACROS`）亮起一枚细小的 `LIVE` 光点标识。

## [C5] 错误提示降噪与多语言（`Localizable.xcstrings`）补齐

### 现状问题
- `F5CaptureDriver`、`CameraBackend` 与部分恢复状态存在未走本地化键的硬编码英文句子，中文界面下会出现中英夹杂；且个别提示过于偏底层校验术语。

### 打算怎么做
1. 梳理 `App/GlassCam/Camera/` 与 `CaptureWorkflow` 中面向界面展示的 `status` / `LocalizedError` 文案：
   - 将底层技术细节留在诊断日志中，向用户展示清晰可操作的短句（例如「相机过热，请稍候再试」「拍摄期间请保持稳定」）；
   - 补齐 `App/GlassCam/Localizable.xcstrings` 的中英文对照翻译，确保全流程语言统一。
