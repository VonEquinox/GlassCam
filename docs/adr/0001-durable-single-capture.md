# 持久保留一张待完成照片

用户要求 RAW 已成功保存在本机后，即使锁屏、切换应用或进程被系统结束，重新打开仍能恢复尚未保存的照片。因此在本机持久保留一张待完成照片及其处理配方，在前台继续处理，并在确认系统相册保存成功后清理。沿用“当前照片保存完成后才拍下一张”的约束，使恢复能力服务于当前拍摄任务；付出的成本是持久状态、迁移和恢复检查，而不是只依赖进程内对象持有临时文件。

用户在 Q12 确认：恢复到相册写入结果未知时保留成片，提示核对相册，由用户确认已保存或再次保存；不自动重复提交，也不为此扩大相册读取权限。当前进程仍在途的请求继续等待原回调，成功回执应先持久化再清理任务；这不是跨系统事务恰好一次保存的承诺。

依据：首版日常试用 Q8／Q9（历史文档 `IPHONE_FIRST_USABLE_20261018.md`，git `72a4ac7:docs/legacy/IPHONE_FIRST_USABLE_20261018.md`）。
