# 真实外围取景与系统 Liquid Glass

用户要求中心照片区保留完整构图，并让真实场景延伸到外围控件下。外围使用相机实际取得的框外画面，系统 clear Liquid Glass 只覆盖照片区外；外围只用于取景，不进入成片。空间不足时采用独立控制面板，不为控件缩小照片区。

选择真实来源和系统材质后，可用范围受更广镜头、视场及场景接缝限制；缺少来源或接缝不可靠时允许遮暗，不以复制、镜像、拉伸边缘或额外模糊制造外围。系统 Liquid Glass 的选择替代了阶段性的自定义玻璃外观，具体拼接和遮暗参数由[外围玻璃](../peripheral-glass.md)定义。

依据：旧决策 D008（2026-10-11）、D017（2026-10-12）、D021（2026-10-20）。布局见[取景](../viewfinder.md)。
