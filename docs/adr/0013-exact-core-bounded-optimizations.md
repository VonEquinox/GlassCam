# 数值内核保留精确参考路径

状态：已被 [0014](0014-bounded-gpu-photo-processing.md) 替代。

优化需要与既有颜色语义共存，因此保留精确数值 API，并让并行、缓存和分条实现与参考结果比较后再用于照片处理。独立的显示近似允许有明确误差预算，但不能以显示路径替换精确内核或最终高位深导出。

这种分离保留了持续检验数值一致性的依据，代价是维护参考路径与优化路径；性能收益需要对应运行环境的测量，线程数量本身不构成加速依据。

依据：旧决策 D006（2026-10-11）。数值约束见[架构](../architecture.md)和[测试说明](../testing.md)。
