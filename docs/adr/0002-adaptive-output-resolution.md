# 按有效像素选择 24MP／48MP 输出，并允许插值

三摄连续变焦会改变最终构图中实际保留的像素，原来的“一律禁止上采样”与用户新确认的输出要求不再一致。保留 24MP／48MP 选择：24MP 档总是输出约 24MP；48MP 档在最终构图有效像素达到 24MP 时输出约 48MP，否则输出约 24MP，保持画面比例并允许必要插值。这样保留用户期望的成片尺寸与变焦构图，代价是文件尺寸可能大于真实拍摄细节；界面和验收记录必须区分有效像素、输出像素及插值。

这项决定替代本轮早先提出的“有效像素原样输出、最低 12MP”方案，以及旧输出策略中适用于所有情况的禁止上采样约束；原有 HNCS／FFCS 颜色数学不因输出尺寸政策而修改。

依据：首版日常试用 Q11 与最终输出表（历史文档 `IPHONE_FIRST_USABLE_20261018.md`，git `72a4ac7:docs/legacy/IPHONE_FIRST_USABLE_20261018.md`）。
