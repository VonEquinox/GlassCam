# 高分辨率 ProRAW 在单摄照片会话中捕获

状态：已被 [0016](0016-main-camera-bayer-capture.md) 替代。

多摄取景配置与高分辨率 ProRAW 的能力限制不同。用户批准在快门时冻结取景，停止多摄会话，再用同一实际镜头及对应视场建立普通 `.photo` 会话，取得照片后恢复取景；不要求多摄会话同时承担 ProRAW 捕获。

这项选择保留高分辨率源能力，代价是切换期间取景短暂停顿及额外的会话恢复流程。源格式和尺寸仍需验证；成功取得的照片保留，即使取景恢复失败也不把照片改报为失败。F5 的 Bayer RAW 捕获使用独立流程。

依据：旧决策 D016，替代 D011 的同时捕获限制。实现见[拍摄与恢复](../capture-and-recovery.md)。
