# 两个持久槽位的连续拍摄队列

状态：现行

日期：2026-11-15

## 背景

多帧重建与 HDR 编码比传感器采集更长，等待整张成片写入相册会错过下一次快门。[ADR 0001](0001-durable-single-capture.md) 的单张事务提供可靠恢复，但把采集与后续处理绑定在同一个准入周期。

## 决定

使用两个独立持久槽位，源照片可靠保留并恢复取景后允许另一次采集，重建和编码共享一个串行处理许可；槽位满时暂停接收快门。每个槽位继续独立冻结配方、保留源照片、记录相册保存回执，并处理重试和未知保存结果。

槽位与 F5 暂存目录一一对应，任一失败或放弃不覆盖另一张照片，重启重新打开各槽位。最近确认保存的成片另存一份供回看，按首次确认时间排序，恢复旧回执不会替换更近的照片。

## 后果

队列限制同时处理大图的内存和待完成照片的磁盘增长，允许处理上一张时采集下一张。界面显示待完成数量，并逐张处理需要用户决定的记录；RAW 诊断记录仅在队列完全空闲时开放。
