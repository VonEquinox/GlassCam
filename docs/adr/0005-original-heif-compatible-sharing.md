# 原始 HEIF 保存与兼容分享分开

用户要求成片保存采用 HEIF，同时要求接收应用能够查看分享的照片。因此保存和文件交付保留最终 HEIF 原件；普通分享提供一个逻辑图像，优先注册原始 HEIC，并在接收端请求时从该最终文件生成兼容 JPEG。JPEG 保留成片尺寸并转换为 SDR sRGB，不新增用户可见的 JPEG 保存选项。

这种分离保留原件的高位深与元数据，也需要管理兼容文件的生成、缓存和生命周期；格式选择仍由接收端协商。此决定承接旧 D007 的 HEIF 保存要求及 D012 的兼容分享选择，D007 的仅 SDR 输出范围由 HDR 输出取代。

依据：旧决策 D007、D012（2026-10-11）。格式与交付约束见[图像管线与成片导出](../image-pipeline.md)。
