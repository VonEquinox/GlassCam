用户要求借鉴想法，继续优化 F5，不引入 JSR 的重型网络。此次只读取了 JSRAnalysis 的技术文档、Python 数学实现和既有验证说明；没有运行或复制其 Controller、RArm、Transformer、SPyNet 或模型权重。

## 与 F5 直接相关的想法

| JSR 中的观察 | F5 的问题 | 本次采用的轻量方式 |
|---|---|---|
| V98 的颜色差细化利用绿色结构；Transformer 的状态与方差随原始观测保留 | 固定 opponent 色度先验会同时惩罚随机彩噪和真实的有色亮度边缘 | 在局部共同颜色方向上分解空间二阶差分；沿该方向与垂直方向使用不同先验，仍由原 RAW 似然决定恢复结果 |
| JSR 对统计量按局部幅度及其平方分别归一化 | 用原始像素噪声衡量已经平滑的引导，会严重低估可靠的颜色变化 | 按 F5 自己的初始化权重传播方差，估计局部颜色变化相对于噪声的强度，冻结本轮权重 |
| JSR 的相位、支持、状态单独保留，不能把融合后的 RGB 当成所有证据 | 对彩色细纹过强地施加跨通道平滑，会压掉真实结构 | 检测到超过引导噪声的色度变化时，降低额外颜色耦合；不强行让每处纹理都遵从固定的 RGB 比例 |

## 局部颜色先验的数学定义

在每个原生 8×8 区域估计正的局部颜色方向 `n`，再以双线性插值和单位化得到每个先验行的方向。`n` 在本次求解中保持固定。选取与 `n` 正交的两个单位方向 `t1,t2`。对 RGB 场的每个空间二阶差分 `H_j f`，使用

`Y_j = nᵀ H_j f`，`C1_j = t1ᵀ H_j f`，`C2_j = t2ᵀ H_j f`。

沿用原有 Charbonnier 二阶先验、正曲率 IRLS、共享样条系数与真实目标 Armijo 验收。变化是颜色投影由固定基变为冻结的局部基。求梯度时必须使用每一行自己的转置，Jacobi 对角必须包含 `lambdaY*n_c² + lambdaC*(1−n_c²)` 对应的加权项；不能仍假设每个通道都占三分之一。

若 RGB 在一段纹理中保持同一比例，真实亮度变化只进入 Y，不会被强颜色平滑一起抹去。真正的色彩变化则不符合这一条件，因此仍需要自适应控制，而不是普遍假设颜色与亮度共边缘。

额外色度约束的置信度来自引导的垂直颜色能量与传播噪声能量。对初始化中的每个 CFA 权重 `w`，方差按 `Σw²v/(Σw)²` 传播。以噪声与观测颜色变化能量的比值限制额外平滑；强真实颜色变化可将权重降回基础值。未把这一近似声明为设备标定或后验置信区间。

平坦区增强实验另以沿 `n` 的引导方差及传播噪声，控制亮度先验的额外倍率。倍率是显式开发参数，尚未成为产品默认值。引导每个粗节点使用 32 字节，4032×3024 原生图约需 6.1 MB；没有神经网络权重或全图注意力。真实全图手机时延仍需后续测量，不能由小裁切的电脑时间推断。

## 初始化与数值改进

原初始化把平滑后的颜色值直接当作样条系数，样条求值会再平滑一次。新增单块实验先构造保留已观测 CFA 位置的双线性样本，再用两次三对角扫描转换为有符号样条系数，并检查全部使用的 RAW/输出位置正值；不可行时和保守初值混合。该实验目前限制为一个原生块，尚未替换全图产品初始化。

另试验过在每次 PCG 中应用样条逆的预条件器。实拍 ROI 没有得到速度或收敛收益，已移除其迭代接线；保留的三对角求解只供初始化使用。

## 验证与结论范围

- CPU 已用有限差分验证空间变化的颜色基、噪声权重和正曲率；相同颜色比例的真实边缘不会被额外色度约束惩罚，孤立颜色扰动会被惩罚。
- Metal 的目标、梯度、Jacobi 对角及 normal product 与独立 FP64 求值对照；三对角逆通过独立矩阵重建残差检查，包括图像边界和块内部边界。
- 新增 `f5_quality_benchmark.py`，用独立解析光学响应、像素积分响应及 Poisson–Gaussian 整数量化生成同色细纹、彩色细纹、暗部与色彩边缘，保留实际停止状态。
- Lucky 对照包含 BM3D 0.75、1、1.25 三档以及轻锐化版本。记录完整六个对照，不能只选择弱对手。该小型合成基准用于开发，不能替代独立实拍与人类放大盲评。

初步结果表明，固定颜色引导确实改善部分纹理，但会损伤真正的彩色变化。加入噪声尺度和色彩证据控制后，彩纹及色彩边缘的误差明显下降。暗部噪声、运动、完整超分收敛与手机时延仍未通过，**不能宣布 F5 已全面超过处理后的 Lucky Image**。

## 统一候选参数的当前结果

当前候选固定为 `lambdaY=.001`、`lambdaC=.04`、局部颜色引导、按噪声调节引导强度、平坦区上限倍率 256 和保留观测位置的 cardinal 初始化。所有场景使用同一参数，不逐图选最优版本。参数见 `validation/f5-20261027/lightweight-candidate-policy.json`。

下表是最终原生融合经共同 2× 插值后的 RGB RMSE 与六个 Lucky 处理版本中最低 RMSE 的比值；小于 1 表示本项误差更小。它不是单独的画质通过规则。

| 场景 | 原开发参数 | 改变方向、频率、位置及噪声样本后 |
|---|---:|---:|
| 同色细纹 | 0.948 | 1.038 |
| 彩色细纹 | 0.709 | 0.362 |
| 暗部弱纹理 | 1.364 | 1.271 |
| 色彩边缘 | 0.649 | 0.553 |

变化参数集仍属于同一解析场景家族，不是外部数据或人类盲测。暗部持续失败，同色细纹存在退步；所有联合求解仍有 `GEOMETRY_PENDING` 或 `CYCLE_LIMIT`，不能称为完成验收。固定已知运动的单独控制能更快达到图像驻点，但其 `CONVERGED_FIXED_GEOMETRY` 绝不作为完整联合收敛。

高分辨率实验也保留了明确的未收敛图：同色细纹局部有改善，其他场景可能比原生图更差。该输出只用于诊断，没有进入产品成片。

## 可证实的计算收益

移除 PCG normal product 中不变 Jacobi 对角的重复计算后，64×64 原生裁切在本机电脑上的总时间：纹理 21.64→16.82 秒、暗部 13.57→12.57 秒，两个输出数组逐值完全一致。分别约减少 22% 和 7% 的时间。来源为 `validation/f5-20261027/normal-cache-timing.json`；不推广为全图或手机时延。

## 后续轻量迭代：局部配准、频域降噪与采样信息

新增局部平移初始化：绿色小块上用 FFT 候选和两变量稳健优化估计平移，再以反向一致性、纹理相关性及不确定度筛选。通过后重新裁取原始整数 RAW 并同步 gain-map 坐标，不插值原始测量。该局部初始化目前用于实拍 ROI 诊断，尚未接入全图产品几何网格。

新增固定 32×32 DCT、步长 8 的 Metal 降噪实验。RGB 正交变换后按噪声门限处理频率系数，保留各块 DC 并重叠合并；没有相似块搜索、网络权重或训练。方法背景参见 [Yu 与 Sapiro 的 IPOL 论文摘要](https://www.ipol.im/pub/art/2011/ys-dct/)；本次实现使用自己的显式正交变换与独立 SciPy 对照，没有迁入 JSR 模型或该论文代码。噪声尺度使用曝光与增益归一化的近似精度和，尚未传播重建后的空间协方差。

固定 v3 参数的结果如下；两组均来自既有解析开发数据，未更换输入或 Lucky 对照。

| 场景 | 开发组：v2 → v3 / 最好 Lucky RMSE | 变化参数组：v2 → v3 / 最好 Lucky RMSE |
|---|---:|---:|
| 同色细纹 | 0.948 → 0.940 | 1.038 → 1.027 |
| 彩色细纹 | 0.709 → 0.709 | 0.362 → 0.359 |
| 暗部弱纹理 | 1.364 → 0.951 | 1.271 → 0.860 |
| 色彩边缘 | 0.649 → 0.634 | 0.553 → 0.523 |

两组暗部 RMSE 比各自原生候选下降约 30% 和 32%，但同色细纹仍有失败项。实拍放大对照显示局部配准减轻运动主体的错位，频域处理降低部分噪声；暗部仍有彩色斑块，细纹仍偏软。不能以合成 RMSE 改善替代真实画质验收。

Metal 与独立 SciPy 最大分量误差小于 `2.4e-7`；64/256 分块及文件流式输入输出逐值一致，覆盖非整尺寸、块边界、零噪声和 HDR 常量。新增流式 API 只保留带边界的小块输入、方差和输出。实测发现 Foundation/Metal 临时对象会累积，因此加入每块 autorelease pool：4032×3024 合成图的峰值进程 footprint 从约 716 MB 降至 86 MB，Metal 自有缓冲约 49 MB，输出逐值一致。最终单次桌面测量约 3.08 秒，包含文件 I/O；这只是该模块，不是完整 F5 或手机性能。

用户提出 OIS/位移不足后，发现并修复原超分信息检查忽略低频混叠未知量的问题。重复位置不再被判成新增分辨率；没有可用信息时不分配高分辨率求解缓冲。详情见 `F5_SAMPLING_DIVERSITY_20261027.md`。

v3 参数、全六种 Lucky 对照、局部配准、独立数值检查和资源测量保存在 `validation/f5-20261027/local-frequency-*.json`。可视化由 `f5_local_quality_report.py` 生成，可切换场景、Lucky 处理强度及 100%～800% 放大。DCT 仍未成为产品默认后处理；新采样信息判断和高网格启动条件已接入产品路径。所有改动仅在电脑验证。

后续增加固定 5×5 初始化和原始绿色采样的细纹保护，并把验证扩大到自然图像模拟内容。原有八个解析开发场景的 RMSE 全部低于最好 Lucky，但新增人像、砖纹仍失败，暗部毛发存在附加降噪退步。完整参数、失败项和实拍复核见 `F5_DETAIL_INITIALIZATION_20261027.md`；没有据此宣布完成最终画质目标。
