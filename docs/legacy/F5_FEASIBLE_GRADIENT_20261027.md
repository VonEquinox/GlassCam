# F5：可行下降备用步与先验对照实验

此页保留 v6 的历史开发结果。后续已按[设计复审](F5_DESIGN_REVIEW_DIAGNOSTICS_20261027.md)冻结 v5 作为诊断基线，优先检查目标尺度、驻点与原生信息；本页的胜出数量不构成独立测试结论。

本轮处理强边缘附近的求解停滞。固定候选 v6 在 v5 的初次 PCG 方向无法提供可用的局部可行下降方向时，尝试一个对角预条件梯度步。它复用原有缓冲和目标函数，不引入网络、模型权重或额外图像缓存。当前仍是开发选项；产品默认没有启用改变画质的实验组合。

## 备用步的含义

当前梯度为 `g_i`，冻结正曲率对角为 `D_i > 0`。先取 `d_i = -g_i / D_i`，再使用已有的物理正值限制缩短负方向分量。令各分量缩放为 `s_i ∈ [0,1]`，则 `gᵀd = -Σ s_i g_i² / D_i ≤ 0`。这一性质使备用方向不会因为缩短局部负分量而反转为上升方向；PCG 的一般方向没有这个逐分量保证。

随后用原冻结 normal operator 计算沿该方向的曲率，试探步长取物理可行上限与 `-gᵀd / dᵀQd` 的较小值。只有真实目标严格降低、满足 Armijo 且物理采样为正，才提交更新。未通过时恢复此前保存的 PCG 方向，继续原有约束阻尼流程。备用步没有降低收敛门槛，没有裁剪有符号样条系数，也没有改变 RAW 观测。

触发条件限于开启 `localStepLimit` 的实验路径、初次 PCG 的可行步长小于 0.5，且局部限制后的 PCG 方向仍不可用。`feasibleGradientFallback` 默认关闭。报告以 `fine_diagonal` 记录实际采用的备用步；不能把该记录中的零 PCG 迭代数当成整轮没有做过初次 PCG。

## 数值验证

独立 C++ FP64 目标验证了完整块和内部条件块更新后的实际目标下降，覆盖原生整数映射、四倍整数映射及空间增益三种输入。测试同时检查预算已结束时返回且不改变图像。原有物理方向限制测试继续覆盖负系数、亚像素 RAW 位置及 1×/2× 网格。CPU、Metal 和完整生产契约检查均保留。

这些检查验证数值行为；画质结论仍来自固定参数的输出比较。参数见 `validation/f5-20261027/feasible-gradient-candidate-policy.json`。所有场景使用同一候选，不按单图挑选算法或参数。

## 没有采用的先验变体

多帧颜色引导先在各帧 RAW 上估计带符号的低频颜色，再对齐引导并估计跨帧颜色变化。一个独立暗部常色控制中，单帧先截正的颜色轴平均角误差约 8.32°，带符号多帧估计约 2.47°。这说明引导统计有改善空间，但不等于最终图像改善。最终人像、暗部毛发的误差分别从最好 Lucky 的 1.0048、0.7115 倍变为 1.0197、0.7393 倍；实拍也未呈现明确改善，因此没有采用。

另一变体在原生求解前，以当前图像的读取噪声、光子噪声及有效帧信息密度冻结先验尺度。它不是后验边际方差。原有 λ 不变时，尺度增大会减弱平滑强度；8 个模拟试点中 7 个退步，人像从最好 Lucky 的 1.0048 倍变为 1.6188 倍，砖纹从 0.9510 倍变为 1.1830 倍。不能仅凭该尺度包含更多物理噪声项就替换原尺度。

上述两个变体均保留为桌面诊断，不进入 v6 候选。完整正、负结果及各次输入、着色器、可执行文件和输出摘要见 `prior-experiment-results.json`。

## 画质与范围

原有 12 个模拟场景中，v6 的附加降噪结果 RMSE 均低于六种 Lucky 后处理中最低的一种。人像比值为 0.9830，毛发为 0.7890，砖纹为 0.9510，暗部毛发为 0.7115。后者仍略差于自身未附加 DCT 的 0.7073，不能把后处理视为总有收益。两组解析场景及砖纹的输出与 v5 保持一致。

这不是全面画质验收。实拍纹理仍偏软，运动边缘仍有彩边；联合图像/运动求解未达到收敛条件。此处的自然图像只是生成模拟 RAW 的内容来源。相同的输出尺寸、曝光和显示曲线用于按像素放大的对照，未用观看距离或显示尺寸豁免问题。完整分辨率恢复、实拍优越性与手机全流程时延仍未证实，目标继续保持未完成。

四种新增内容（咖啡细节、草纹、火箭边缘、相机与织物）使用另一固定噪声种子，同时比较 v5、v6 和六种 Lucky 后处理。它们在 v6 参数确定后加入，用于扩展检查，不替换原有失败证据。结果记录在 `feasible-gradient-extended-comparison.json`。

| 新增内容 | v5 / 最好 Lucky RMSE | v6 / 最好 Lucky RMSE |
|---|---:|---:|
| 咖啡细节 | 0.6538 | 0.6499 |
| 草纹 | 0.9320 | 0.9318 |
| 火箭边缘 | 0.9666 | 0.9668 |
| 相机与织物 | 0.9859 | 0.9860 |

新增四项也低于各自最好 Lucky，但最后两项相对 v5 略有退步，不能宣称新版本对所有内容都优于旧版。总计 16 个模拟场景、5 个实拍裁切的全部六种 Lucky 对照见 `feasible-gradient-quality-comparison.json` 及实拍诊断目录的 `feasible-gradient-review/review.html`。

同一可执行文件、同一着色器下，两项 64×64 桌面配对计时为：人像 18.16→6.45 s（减少 64.5%），实拍左侧纹理 14.73→5.85 s（减少 60.3%）。各仅一次配对测量，没有当作稳态中位数、整图或手机性能。27 次最终渲染的输入和输出摘要已逐个校验；最终的严格下降检查保持 17 个原有案例输出逐字节一致。详情见 `feasible-gradient-provenance.json`。

最终 CPU、Metal、完整生产契约、HDR HEIF 输出链路和 iOS Release 编译均通过，记录于 `feasible-gradient-checks.json`。没有连接或操作手机。
