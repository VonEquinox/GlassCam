## 两份分析对应的落地修改

| 问题 | 当前实现 |
|---|---|
| ambiguous 结果的小区间被丢弃 | 保留每段拓扑；完整搜索、信号和独立最佳反向检查通过后，多候选集合仍可保留区间。全边界区间完备时允许 `.ambiguous` 成为可靠几何证据，不强制唯一峰 |
| 单方向信息被丢弃 | 单独保留法向区间；反向检查也投影到同一法向，不把切向不可观测当作法向失败。法向证据只用于可见结构，不冒充二维范数上界 |
| 低结构远峰被误当成大错位 | 给几何区间和严重位移分支加入预滤波信号下限；保留重复候选簇。天空弱峰仍可为未知；不写成零 |
| 旧测量被最新帧的累计运动否决 | 接纳测量只检查它自身的输入帧、时间、epoch、接缝和画幅身份。真实纹理来自这份测量的原始外围帧，不把旧 H 或颜色直接套到新帧 |
| 最新中央预览仍可能与外围不同步 | 绘制前计算已认证中央帧到最新中央帧的端点运动；单位明确为宽 192 的分析像素，并按短边和屏幕 framing 换算。无端点估计时可用完整原生边界的同相机外观检查，仍不制造运动值 0。超过预算或两条检查都未知则遮罩，不清掉独立测量恢复 |
| 全局几何认证被天空边缘卡住 | 在原有接缝对应之外，加入分布在画面内部的 3×3 独立匹配，重新认证当前 H。选择新 H 不能继承旧 H 的认证时间 |
| 光度认证与几何绑定过死 | 物理对应的全局 gain 与可见接缝的当前颜色模型分开。前者有独立身份／截止，后者须在当前原生支持上验证，不反向续签物理几何 |
| 无法准备首张纹理 | `PeripheralTextureStore.prepare` 不依赖透明度和 GOOD；合法矩阵、覆盖、帧身份与预算满足即可后台准备。没有可覆盖的 Vision／标定候选时可提出居中 FOV 候选，但它也必须通过图像检查，不能当成证书 |
| 等 GPU 会不断清恢复 | `PeripheralReadiness` 与质量策略独立。notPreparedYet 保持资源遮罩，质量恢复照常推进；资源就绪单独淡入 |
| 纹理与 H／gain 的身份可能分离 | 不可变 Bundle 同时持有原始 pair、分析结果、H、实际光度参数、revision、epoch 和 command ticket。GPU `.completed` 后才发布 |
| 新 UNKNOWN 直接替换好资源 | 可以准备 UNKNOWN，但保留仍在自身固定期限内的完整好资源；UNKNOWN 不授权新显示、不续证书、不延长旧像素硬年龄 |
| GPU 失败／迟到 | 失败资源不能进入 displayable；有界重试与冷却。旧 ticket／revision／epoch 完成事件不能恢复新源的资源 |
| neverCertified 和 expired 混淆 | 策略区分 never-certified；诊断分别给出认证状态、全部 gateReasons、重新获取尝试、支持量、成功时间、下一次配准尝试时间 |
| 运行时 F 不透明 | 保留已有图像坐标方向；记录实际 bitmap F、坐标域、独立探针距离及阈值。未验证的工厂 F 继续走完整二维搜索，不使用实拍事后拟合 F 作为生产标定 |

## 可见接缝合同

`PeripheralEvidence.interval` 继续只表达有效几何候选集合。新增 `visibleSeam` 表达当前映射下的可见一致性；平坦区域可以有 `visibleSeam.compatible=true`，同时几何 status 为 unobservable、interval 为 nil。记录和策略明确显示使用的依据。

原生检查读取双路真实原始像素，按实际源尺寸对 H 做 `S H S⁻¹` 换算，并直接采样原始外围图。不会把 192 像素配准图放大来冒充原生支持。保留的每条 RGBA 验证带都没有预先施加颜色补偿。

检查覆盖实际边界的最外一行、最外一列和附近支持带。匹配模板以外的边界缺陷不再遗漏。法向结构使用双向原生边缘距离、连续无对应长度和细线支持检查；两镜头的锐度不同，因此用显著边缘寻找弱对应的迟滞判据，避免“一个清晰、一个略模糊”本身被当成遮挡。许可仍要求至少一路有强结构，以及另一侧的弱对应和距离检查，不要求两路都达到强阈值。新增同位置清晰线／模糊线正例和移开模糊线反例。近乎平坦的资格同时检查双路原生方差、范围、噪声、沿线结构和实际可见支持的周期性。来自较深模板的歧义不自动否定当前可见平坦带；当前可见周期结构也不因低分辨率变平而获批。

这些是有明确单位的经验门槛，不是已校准的概率覆盖率或人眼可见性保证。原生距离和颜色门槛应继续用独立标注数据校准。已有可靠大位移／局部严重错位有否决权；颜色模型不能抹掉这些证据。

## 颜色模型与实际渲染

每条边独立估计颜色。保留线性 RGB gain，并增加有界的 sRGB 仿射模型 `reference = slope × outer + bias`，使用固定采样网格和 Huber 权重抑制局部遮挡／错位离群值。

- 线性 gain 与仿射 slope 均限制在 0.5–2，bias 限制在 ±0.12 sRGB。
- 连续更新有独立时间状态和限速；启动或旧状态超过期限后可重新获取。
- 参数在每条完整边上选择，不能逐像素挑选较小残差。完整原生支持验证拟合网格以外的像素；相同通过情况保留旧模型。
- 若线性模型已通过，保持线性模型。仿射拟合只作为候选，不能因模型更灵活就强制使用。
- native verifier 与 Metal 使用完全相同的输入域。仿射分支先把线性纹理编码到 sRGB，校正后再解码回线性；没有重复 gain，也没有改变 RAW／HNCS／FFCS 成片流程。
- 常规边区使用该边的模型，角部按框外距离混合各边的线性输出；中央照片仍被 shader 丢弃，中央预览不参与变形或调色。

原生检查看的是**施加实际将被提交的颜色参数后**的残差，包含局部颜色残差、连续强差异和结构缺陷。当前算法仍不能恢复原始相机已经裁掉的高光信息，也不能用单个全局单应消除多深度视差。

## 时序、资源和验证边界

质量策略保留 5%／10% 映射、8% 恢复阈值、0.4 秒连续新证据、0.3／0.4 秒动画和 200 ms 固定期限。先处理旧期限，再接纳新观测；重复 ID／旧 epoch 不续期。新几何版本号本身不清空恢复。

主相机预览继续独立更新。外围分析仍有界分频，纹理取分析对应的帧；Metal 绘制刷新不等于每次都有新的相机外围帧。端点运动预算保护这一时间差，无法可靠检查时仍会遮罩。没有将此轮 Mac 的计算耗时当成手机帧率、热状态或功耗验收。

## 12 组实拍重放

原始 ZIP 仍为 SHA-256 `010a54b0b0594d856269a049d24f2a3e8d6aa528620666955a522bf811dbe170`。重放校验所有原始文件，按真实 stride 恢复原生 YUV，并保留原始颜色标签、PTS、K、R／t。报告分别运行冷获取和记录 H 作为待验证候选的获取；后者没有把记录 H 当成已经通过的证书。
