# 曲线、预设与显示导出

Film Curve 和预设后置曲线是两个阶段。先运行颜色核心与 Film Curve，再应用预设的 Gamma、点曲线和对比度。

| CLI Film Curve | type | legacy | lstar |
|---|---:|---|---|
| as-shot | 4 | 使用 raw-film-curve，默认2 | 同左 |
| standard | 2 | V1 gamma | V1 L* |
| low-contrast | 6 | V1 gamma | V1 L* |
| high-contrast | 1 | V1 gamma | V1 L* |
| old-standard | 0 | original gamma | V1 L* |
| linear | 7 | pure gamma | pure L* |

共有 **五张非 HDR 表**：original gamma、V1 gamma、pure gamma、V1 L*、pure L*。类型1…6共用相应 V1 家族；Reproduction 强制 type7。Linear 仍有 ICC 所需编码。As Shot 的2是目标 X2D II 参考值，`--raw-film-curve` 可显式指定；不要将它解释为从任意 Sony RAW 自动读取哈苏字段。

original gamma按i=0…65535构造：t=i/65536，v=65536*t^(1/4.1)，s=48/50。v<32768时d=s*(v²/32768-v)；否则u=65536-v，d=s*u*(1-u/32768)。结果为clip(65536*clip((v+d)/65536,0,1)^(1/.76),0,65535)后截断uint16。其余四张全长Film Curve随工厂NPZ分发。

## 原生预设曲线

43 份 XML 原文参数存于 `phocus_presets.json`。工具级 XML 作为局部设置覆盖完整 Standard 基线，再交给原生 `CImageCorrection` / `CCalculatedCurves`，得到每组65536项 contrast、luma、R/G/B 表。相同数组按 SHA-256 去重，当前为6张独立表，保存于 `phocus_post_curves.npz`。

Nature 控制点 `(0,0),(71,31),(184,223),(255,255)` 定义平滑曲线，内部点不是必须经过的节点。直接使用原生全长表：71/255输入的红输出约60.514/255；Lighten 的96/255输入约109.226/255。数组码值及量化以 NPZ 为准。

Extra contrast 保存 Contrast=10、Gamma=2.2、EV=1。原生有效 Gamma≈1.2000000477；Gamma=2.0为有效1。EV是**倍率**，1表示0档，与 CLI `--exposure` 的档数分开。

预设 RGB 顺序：饱和度的编码 RGB 标量调整→量化成uint16→原生通道/Gamma表→原生对比度表与色相恢复→可选 luma→灰度→便携颗粒→可选USM→clip/rint到uint16。对比度不使用围绕.5的线性乘法。

`apply_post_curves` 先按各通道输入码查 R/G/B 表；以这个结果查 contrast。色相恢复保留查表前的 H，使用查表后的 HSL 亮度/饱和度；按原生 float32 比率重建，并在最终 clip 后截断。当前所有工厂设置的 luma 点数为2，未启用额外 luma 调整。无色调调整的预设跳过该阶段，Standard 保持基础颜色核输出。

`--no-preset-tone-curve` 只跳过用户 Points，保留 Gamma/对比度；提取器同时保存 tone/no_tone 两组表。固定 native filter 向量检查覆盖 Nature、Lighten、Extra contrast 的灰阶和彩色输入。

## WB、裁切与空间效果

固定 WB 在颜色核心前施加完整目标哈苏增益，捕获 WB 仍负责光源响应选择。Square Crop 取当前宽高中较小者为边长，居中裁切，奇数边缘最多相差1像素。其他明确相对裁剪按输入尺寸解算。

饱和度为 `mean+(RGB-mean)*(1+s/100)`；灰度权重取 GrayScale[1:4]/100。Film Grain 为固定 NumPy 随机种子加多尺度 Gaussian 噪声，受 XML Amount/Color/Roughness/Size/Type 控制。USM 为 Gaussian unsharp，amount=USMAmount/100、sigma=max(USMRadius/10,.1)，按 NoiseLimit/65535 屏蔽小细节。USMDarkLimit 只记录。

镜头、除尘、透视、降噪、场景校准及专有空间内核保存在 provenance。颗粒、USM 与饱和度/灰度是本项目的便携定义，未作完整厂商逐像素等价声明。CLI 默认对带 USM 参数的非 Standard 预设启用近似锐化，`--no-sharpness` 可关闭。

## 显示转换与 DNG

ICC 描述工作 RGB 编码，不包含完整外观逆函数。legacy 解码为 encoded^(563/256)；L*解码在码≤.08时除24389/2700，否则 `((code+.16)/1.16)^3`。乘工作 RGB→XYZ，按矩阵行和白点做 Bradford 到 D65，再乘 XYZ→sRGB、clip并编码。sRGB超色域直接截断，没有感知色域压缩。

主 TIFF 为uint16并内嵌对应工厂 ICC。sRGB TIFF同为16位；全尺寸JPG按 `(uint16+128)//257` 转8位，quality98/subsampling0。预览对编码工作码做面积平均后转sRGB。

DNG 保存完整未应用 HNCS 的uint16 CFA，记录CFA/黑白电平、ActiveArea、DefaultCrop、方向、LibRaw XYZ→camera ColorMatrix、AsShotNeutral与普通EXIF。Sony私有MakerNotes不迁移。导出后重读，full/visible CFA逐样本一致、WB与矩阵误差<1e-6。

原色对照实际从DNG按拍摄WB、AHD、LibRaw相机矩阵与sRGB传递函数显影，关闭自动增亮；它是明确的LibRaw基准。CFA相同不保证ARW/DNG容器所有后续显影像素完全相同，JSON另记录最大/平均/P99差。TIFF保留方向标签，JPG实际旋转。
