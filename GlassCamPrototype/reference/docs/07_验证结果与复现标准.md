# 验证结果与适用范围

当前版本的验证文件位于`validation`。测试固定Python3.12、NumPy2.5.3、SciPy1.18.1、rawpy0.27.1、Pillow12.3.0、tifffile2026.9.20；环境实值记录在delivery_verification.json。

| 检查 | 结果与范围 |
|---|---|
| 单元测试 | 36项通过，包括完整WB、方形裁切、原生预设滤镜与TIFF接入 |
| 工厂颜色核原生对照 | 52组、260000像素，最大uint16差0；两空间×两意图×13工厂坐标 |
| 随包独立参考实现 | 52组6656固定原生像素，最大差0 |
| Nature/Lighten/Extra contrast | 4组共278528像素：完整65536灰阶与4096随机彩色输入；原生滤镜最大差0 |
| Film Curve | 两空间、两意图、type0…7的32项全长表与原生匹配 |
| 六种固定WB | 加载X2D II配置后的增益反向CCT/Tint通过；WB选择实际进入像素映射 |
| Square Crop | Sony、哈苏、竖图、奇数尺寸均为居中正方形；6374×9566 Sony输出6374×6374 |
| 日光18有彩块留一 | mean ΔE00 .3629；共享中性WB和曝光 |
| 暖光18有彩块留一 | mean .4382；同上 |
| 同场景暖光不同曝光 | paired mean .4320/max1.0470；以本实现哈苏颜色核为参考 |

原生预设向量由镜像里的XML经原生CImageCorrection、CCalculatedCurves与CGradationFilter生成；Python实现未向原生对象注入曲线数值。工具局部设置叠加Standard基线，保留版本字段。原生与Python的比较在颗粒/USM之前，不能扩大到专有空间效果。

`tools/verify_delivery.py`逐项验证不可变文件SHA，并执行独立颜色核和原生预设固定向量。`tools/check_isolated_render.py`从当前运行文件在临时目录渲染DSC07247，检查工作TIFF、两个sRGB TIFF的全部像素哈希、方向、主ICC与完整DNG CFA。`tools/refit_delivery.py`隔离重拟合并核对日光/暖光矩阵、WB和工厂坐标。每次执行会更新当前报告。

数值复现要求矩阵方向、float64颜色核、float32预设边界、rint/截断位置、全长曲线和LUT相同。图片复现还要求相同RAW SHA、WB、模式、空间、预设、曝光、ICC与方向。TIFF/JPG容器SHA应独立比较，不能从像素一致推断文件字节相同。

配对模型的准确度只在已取得色卡上验证；WB和曝光归一化会隐藏这两部分误差。没有第三组独立光源/新场景的准确度证明，同WB不同光谱和混合光无法仅靠WB分辨。

完整Phocus RAW链还包含传感器校正、私有解码/曝光、镜头、HDR、局部WB、闭环配置和空间内核。实际Phocus整RAW色块对照的meanΔE00为1.8800，不能宣称全图逐像素等价。当前核心及指定预设对照通过，只证明该明确范围。
