## 根因与改动

旧策略在证据经过绝对 200 ms 截止时重新锁黑，同时清除 0.4 s 的恢复历史。实际手机中，相邻已验证捕获的间隔仍约 83–117 ms，但计算及上传延迟会让旧结果在新结果到达前短暂过期。每次约数帧的间隙都清零恢复，持续正确的图像也永远积不满 0.4 s。

修复将**当前显示证据是否有效**与**连续合格捕获的恢复历史**分开。过期当下仍全遮罩；新的独立合格捕获到达时，若捕获间隔没有超出 200 ms，继续恢复历史。长间隔、源丢失／更换、恢复中的未知结果或确定错误仍分别触发重建／重置。证据的原始绝对截止时间没有被推迟。

GPU 资源就绪的淡入改为累计合法就绪的时间。短上传间隙仍立即遮住当前画面，但不再反复从头计时；超过 200 ms 的资源缺失会重新淡入。该历史不能让无效纹理显示。

Tolerance 及匹配阈值没有在本次修复中继续放宽。
