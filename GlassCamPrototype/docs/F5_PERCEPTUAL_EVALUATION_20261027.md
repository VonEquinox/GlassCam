# F5 放大观看与视觉感知评估

## 用户目标与观看方式

目标保持为：**完成 F5 算法的迭代和优化，使生成图片的质量完全超越经过降噪等处理的 Lucky Image。**

2026-10-27 的补充要求是阅读并考虑人眼感知、分辨能力与图片偏好，并以**放大观看**为主要验收方式。因此，固定观看距离、显示尺寸、整图缩略显示或外围视觉的低敏感度，不作为降低成片细节要求的依据。每个局部都可能被放大并移到视线中心。

主对照保留最终输出的原尺寸像素，提供 100%、200%、400% 的等倍率局部显示及继续放大的原文件。200% / 400% 的证据图采用相同的最近邻显示放大，避免查看器插值改变结论；成片自身的原生/高分辨率重建和最终采样另行记录。倍率不是恢复能力，不把显示放大产生的新像素算作恢复出的结构。

## 固定对照流程

1. Lucky 从合格主曝光帧中按扣除噪声的细节评分选择。当前实拍选择第 2 帧（零基索引 1）；第 4 帧得分非常接近。保留评分、选择规则和原始数据哈希。
2. `f5_lucky_baseline.py` 只读取被选中的单帧进行降噪。流程为广义 Anscombe 变换、四个 CFA 平面的 BM3D 硬阈值与 Wiener 两阶段处理、近似无偏逆变换、Malvar demosaic、原始 DNG 的增益图。BM3D 版本为 4.0.3；使用 DNG NoiseProfile 估计噪声，并明确它不是独立设备标定。
3. 提前声明 0.75、1、1.25 三个降噪强度，额外保留固定轻微锐化版本（半径 0.6 原生像素，量 0.35）。不通过只选一个较差的 Lucky 处理结果建立优势。每个区域额外读取 128 原生像素上下文，避免直接在小裁切边缘降噪。
4. F5 与所有对照保持同一参考几何、曝光归一化、颜色矩阵、白平衡、色调、裁切和输出尺寸。原生融合放大输出须标明，不能称为通过了超分验收。
5. 固定的亮部、暗部、左右纹理和运动主体区域均保留。参数开发用过的图明确标成 development；最终验收须有独立场景，不能把反复调过的图称为盲测。

## 通过证据

- **细节正确性：** 有独立真值时检查线对/细纹的方向、位置、相位、幅度和颜色；检查文字与结构可辨性。边缘变陡或高频能量增加本身不证明信息增加。
- **噪声：** 在固定平坦区域分别测亮度、两个颜色方向的残余噪声及空间功率分布；放大检查彩色颗粒、色斑和规则纹样。同步检查邻近的低对比纹理，防止通过涂抹获胜。
- **边缘与纹理自然感：** 检查过冲、白边/黑边、振铃、重复图案变形、假细节和不自然的塑料感。感知指标只提供辅助证据。
- **运动与 HDR：** 运动物体、树叶、遮挡边缘和亮部过渡须单独检查，不能用静态局部均值掩盖重影、伪色和高光缺失。
- **放大成对评估：** 随机左右顺序、相同倍率和处理条件，分别判断细节辨认、噪声/伪影与总体偏好。只记录实际收到的人类判断，不由自动指标冒充盲评结果。

没有独立真值的实拍不报告“真实性 PSNR”。不能把另一个算法输出或多帧均值未经验证当作无误真值。尚未收到盲评、没有独立场景或仍存在明显质量退步时，目标保持未完成。

## 本轮已观察到的问题

局部可行性阻尼已在独立二次问题上解除单个暗像素对整块更新的限制，Metal 也通过了独立的 `BᵀWB` 能量核对。真实暗部的步长明显增大，原始数据目标下降更多，但放大后的彩噪反而更明显。当前局部曲率先验在弱正则时过拟合噪声，在强正则时会损失看台方格等真实纹理；这正是必须同时检查数据拟合和放大观感的实例。

**当前仍未证明 F5 超过经过 BM3D 的 Lucky。** 下一步需要改善噪声与纹理的联合处理，并在相同输出条件下重新核对固定区域及独立场景。
