# 处理管线目标与当前边界

目标是可逐阶段检查并与参考对照的 RGB/RAF 颜色管线。v0.2.0 已实现输入色彩管理、Gamma/线性分支、矩阵、3D 映射、独立 Lab/OKLab 与色调调整、颗粒、锐化和 ICC 输出。传感器路径在其前执行黑电平、同 CFA 坏点修复、径向增益、同 CFA 水平滤波、按站点白平衡、去马赛克、阴影整理和 Lanczos 缩放。内嵌 JPEG 路径保留已有显影结果，传感器占位阶段标记不适用。

| 验收项 | 目标 | 当前证据 |
|---|---|---|
| 默认原生颜色映射 | 平均 ΔE2000 <1 | 全部 50 张表通过，100,000 样本 |
| ColorChecker24 全链 | 平均 ΔE2000 <2 | 指标/框校验已实现，尚缺独立配对参考 |
| 颗粒 | 残差方差与频谱一致 | FFT/残差统计已实现，尚缺原生参考 |
| 传感器 RAW 全链 | PSNR >35 dB | 计算和域门槛已实现，尚缺真实配对 RAF |
| 阶段覆盖 | 必需阶段可逐项比较 | 接口覆盖已实现，不能据此宣称行为等价 |

内置 RAW 参数、解析外观和非默认 sigma 为明确记录的近似。后续定量标定需要同一真实 RAF、参考软件设置与配对输出/阶段；先定位残差再修改对应步骤，保留最大误差和未验证状态。禁止将预览处理、机型表替代或确定性自我复现当成原生全链证明。

当前实现规格和全部参数见 `FFCS_技术实现完整交付/docs/`，修复记录见 [FIXES_20261013.md](FIXES_20261013.md)。
