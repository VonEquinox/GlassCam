# 独立重建实施规格

## 1. 重建目标与依赖

目标是实现本快照的相同函数，不仅外观接近。其他人可直接安装 implementation，或以其源码和数值规格为依据用其他语言重写。LUT 与 ICC 必须使用随包数据；一个三维颜色函数含百万级离散数值，不可能从胶片名称恢复。若需替换 Pillow 图像 IO/缩放，必须逐项证明边界、精度、编解码行为一致。

## 2. 最小完整颜色流程伪代码

```text
resolve simulation and camera
if cube supplied:
    load cube and assign domain/source/size
else if bundled enabled and camera/look found:
    assign PackedLUT, header matrix, encoded domain
apply optional sigma override
copy explicit pixels, or normalize decoded image
store input_normalized
linear = pixels if input_is_linear else srgb_decode_each(pixels)
store gamma_pre
if encoded:
    matrix_pixels = sim_matrix(linear) with per-call clip
    lut_output = map_lut(srgb_encode_each(matrix_pixels))
    encoded_pixels = lut_output
else:
    matrix_pixels = sim_matrix(camera_matrix(linear)) with both clips
    lut_output = map_lut(matrix_pixels)
    encoded_pixels = srgb_encode_each(lut_output)
store matrix_3x3, lut_3d in their own domains
lab_pixels = adjust_ucs(adjust_lab(encoded_pixels,saturation,hue),1,1,0)
if not encoded and (acros or saturation==0 or sepia):
    lab_pixels = monochrome_or_sepia(lab_pixels)
store lab_ucs
store tone_curve(tone parameters)
store film_grain(hash(seed),grain parameters)
compute grain statistics over grain image
store sharpen(truncated 3x3 mean)
output = sharpen if sRGB else convert_to_AdobeRGB(sharpen)
store output_icc
build stage domains and coverage
export if stage_dir supplied
```

map_lut 必须实现 BGR axis/channel、三线性插值、夹取和 sigma；无表时运行解析函数。tone/grain/sharpen 的预设不随内置查表清零。阶段存的是各时刻的像素快照。

## 3. RAW 重建顺序

优先 rawpy 传感器，否则预览；记录 decoder。传感器二维标量按 black→bad→shading→horizontal filter→WB→CFA mean→shadow→resize。预览 RGB8 按对应 RGB 函数处理，demosaic 为恒等。接入颜色链使用 resize 的浮点数据；按 config 决定 Gamma，不自行根据 decoder 改动。

## 4. 数值细节清单

| 位置 | 必须保持的行为 |
|---|---|
| 输入 | sRGB 假设；RGB16 自定义路径不做 EXIF/ICC 转换 |
| 矩阵 | 行主序、每次乘完 clip、camera 与 sim 顺序 |
| 表 | N-1 缩放、floor、上界合并、x→y→z 插值顺序 |
| PackedLUT | 输入交换、uint16/scale、输出按 flags 交换 |
| sigma | clamp 到[0.05,8]，近1时跳过 |
| Lab/OKLab | 精确常量、白点、往返、保留中性微误差 |
| 解析 look | LUT 阶段与后处理参数重复作用 |
| tone | 先contrast，再toe，再用更新值算shoulder |
| grain | 32位掩码、坐标 int 截断、seed+17、图宽 scale |
| sharpen | 3×3 包含中心、边缘截断、radius不参与 |
| 输出 | AdobeRGB显式转换、ICC单独嵌入、Python round |
| RAW | CFA周期字符、RGB前三个黑电平/WB、边界邻域 |
| resize | Pillow F float32 Lanczos；factor=1不缩放 |
| 比较 | 数值域、stride、缺失/形状检查、非严格JSON特殊值 |

## 5. 推荐实现与校验顺序

先实现读表与 Gamma/矩阵/插值，利用边界像素和 baseline_pixels 的前四阶段定位轴或领域错误。然后加入 Lab、OKLab 和单色判断，再色调曲线、hash 颗粒、锐化与输出空间。最后做文件 IO、RAW 分支、完整 metadata 与 CLI。

只要首次不一致的阶段确定，检查该阶段的输入、常量、夹取和运算次序，避免用整体调色补偿上游错误。逐阶段基础值对应 fixture 的坐标 [y][x]；期望值在 `validation/baseline_pixels.json`。测试命令 `python examples/reproduce.py` 对所有阶段检查绝对误差<=1e-12，之后检查保存和读回的16-bit量化误差<=0.5/65535+1e-12。

## 6. 扩展时保持兼容

优化向量化/并行/GPU 可能改变浮点结合顺序、边缘与量化；增加RAW校准或高质量去马赛克会改变现有输出。建议保留当前模式作为版本化基准，新模式明确指定并另存基准和验证范围。新增机身表须连同矩阵、domain、axis_order、channel_order、scale、哈希和选择规则一起提供。
