## 2. 完整交付与可移动性

implementation 包含全部.py、48个.lutz、2个.icc、3份原数据manifest、模型数据README、tests、pyproject.toml、MANIFEST.in和.gitignore。交付根还包含重写文档、运行/验证示例、参数、资产、基准和实测记录，。无指向原项目的数据软链接，代码查找数据从模块自身目录开始。

运行依赖Pillow；测试依赖pytest；安装构建依赖setuptools/wheel。requirements-verified.txt固定本次实测工具版本，依赖文件本身不含Python解释器或离线wheel，因此首次安装需要可用软件源或预先提供离线依赖。RGB颜色数据都已本地包含。

## 3. 完整性校验

```sh
python examples/verify_delivery.py
```

遍历delivery_manifest.json所列文件，以相对交付根的路径读取并验证大小和SHA-256；额外列出/校验48个LUT格式和各相机原manifest hash。安装后生成的__pycache__、egg-info、build以及examples/generated不在静态交付清单里，不会导致误报。

delivery_manifest.json不能包含自己的hash，否则形成自引用；它列出其余所有正式交付文件。若发布者修改交付文件，应重新生成hash和数值基准并重跑验证，不能仅手改状态为pass。

## 4. 阅读与复现的验收点

读者应能回答：输入是什么域；机身与模拟如何选择；哪张表被使用；矩阵、轴与通道顺序如何处理；每个阶段公式是什么；随机纹理如何固定；数值如何保存；RAW在何种条件下回退；哪些数值有本次实测支持，哪些只来自历史记录。10篇说明、完整源码和基准提供上述信息。

按README安装，再运行示例、原测试及hash检查。需要真实RAF和独立参考测量时，应另提供对应输入/输出fixture；现有项目未包含，不能在交付中臆造测量结果。

此次上传排除所有安装包和图像，包括 DMG/PKG/EXE/MSI、PNG/JPEG/TIFF、RAF 及 examples/generated 全目录；同时排除 __pycache__、build、egg-info 和测试缓存。LUT 与 ICC 是颜色变换所需数值数据，保留完整文件。压缩包逐项核验，不含上述被排除文件。
