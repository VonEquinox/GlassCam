# 07 验证指标与复现边界（0.2.0）

61 项回归测试：原码/线性域、CFA饱和场、双绿元数据、预览选择/保留、TIFF位深/方向/planar/压缩、ICC暗部精度、输出标签、宽色域ΔE、色卡框、形状、滤镜顺序、LUT默认调整、Cube域/shaper、锐化半径、频谱完整性、容器损坏和严格JSON。作者 CIEDE2000 34 对公开 Lab 数据以 <5e-5 误差验证公式，不仅做自身相等测试。

所有比较要求非空矩形有限 RGB 三元组、相同形状；PSNR=`10log10(peak²/MSE)`，完全相等返回 +∞（JSON 为字符串），显示域 peak=1，sensor-code 根据参考量程。形状不一致不会截短 zip 并报告完美分数。`stride` 必须正整数。

ΔE2000 按两侧实际 stage_domains 分别转 D65 Lab；AdobeRGB 直接入 XYZ，避开 sRGB gamut 裁剪。不同编码域 PSNR 先转换共同 XYZ。CFA/原码只做数值 PSNR 与 max_absolute_error；域不符明确 invalid。ColorChecker 输入文件按自身 ICC 直接转 Lab，24 个独立有效框的均值色度再算每块 ΔE。

| 门槛 | 判据与限制 |
|---|---|
| LUT 色彩 | 平均 ΔE2000 <1，明确指定数值域 |
| 图像端到端 | 平均 ΔE2000 <2，逐像素整图指标，不代替24块色卡指标 |
| ColorChecker24 | 所有24框有效，24块平均 ΔE2000 <2 |
| 传感器 RAW | 两侧 decoder=rawpy-sensor，resize阶段 PSNR >35dB；preview 无法验证 |
| 颗粒 | 残差方差与完整同方法同形状频谱精确一致；无容差声明则不推测容差 |
| 文件覆盖 | 必需实际阶段文件都在，而非只信 metadata 的 present |

缺失/损坏/尺寸错误会失败；缺少适用指标证据为 unverified。非零残差另逐阶段列出，阈值通过不意味着逐像素相等或残差已解释。`compare` 的通过是该比较对象及门槛的结果，不把参考来源自动视为官方。

原生映射本次实测 50 张×2,000=100,000 样本，最高单表 mean ΔE2000=0.0540214251，全部 <1。调用显式 TransFormTrilinear 并执行头 Gamma，以 sRGB 约定计算 Lab；证据含每表均值/P95/最大误差及源/封装/库 SHA。运行时 hash 校验后才展示证据，并标记 sigma!=1 不适用于当前映射。测量文件见 [native_reference_validation.json](../validation/native_reference_validation.json)。

复现程序生成合成 RGB、预览 RAF、sensor plane，检查固定版本浮点阶段基准与 TIFF16 量化；验证容器、文件 hash 与独立 wheel 安装。这些与真实 RAF/原生 GUI 配对验证不同。当前没有真实 RAF、GUI、独立 ColorChecker 参考，也没有原生颗粒或非默认 sigma 对照。RAW 标量、机型公共表替代、解析外观维持 unquantified。

v0.1.0 原有 baseline/ZIP/报告保存在项目 `audit_review/history/v0.1.0/`；交付 historical_core_validation.json 是历史记录。本次 baseline 是修复后新版本基准，不能把其生成看成缺陷正确性的证据；正确性由独立回归输入和原生映射对照支持。
