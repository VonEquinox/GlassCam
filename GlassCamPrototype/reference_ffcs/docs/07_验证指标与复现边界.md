# 验证指标与复现边界

## 1. 区分三种一致性

阶段覆盖只证明指定名字存在。确定性复现证明同份 FFCS 代码/资产/输入/配置在实测环境下输出一致。参考等价需要独立参考图及阶段数据。三者不可互相代替。

本次交付保留所有原有 Python 源文件和表数据；原项目没有真实 RAF、ColorChecker 成对图、逐阶段参考 TIFF、完整 LUT 数据生成程序及历史随机样本。能够复现现有数据驱动运行，但不能仅凭文字重新生成每个原始 LUT 数值；因此全部 LUT 是必要输入并已随包交付。

## 2. 阶段比较

compare_stage_maps 取阶段名并集、排序；一侧缺失报告 status=missing；高宽不一致报告 shape_mismatch 并跳过数值比较；一致时给出 delta_e2000_mean 和 psnr_db。常规成功阶段没有独立 status 字段。比较均按像素位置对齐，不执行配准。

mean_delta_e2000 的 stride 使用 max(1,stride)，从0开始同时抽样 x/y。linear、linear-rgb、linearcamera/workrgb、linear-sensor 域先 E 编码；AdobeRGB 域先转 sRGB；其他域直接当编码 sRGB，再转 Lab。所有用于 Lab 的色彩转换都带颜色夹取。若两侧域不同，当前代码没有分别解释，而用合并后的单个 stage_domains；应确保双方导出的域一致。

psnr 将所有对应 RGB 通道平方差均值作为 MSE，以 peak=1 计算 `10*log10(1/MSE)`。MSE<=1e-20 返回 Infinity。独立 psnr 函数按 zip 截断、不会自行检验尺寸；阶段比较外层才检验尺寸。PipelineResult.compare 的 __output__ 单独调用均值和 psnr，也没有等价的输出尺寸拒绝检查。

## 3. CIEDE2000 精确计算

完整可执行公式在 metrics.py::delta_e_2000。实现采用角度制规则，三角函数调用前转弧度，权重 kL=kC=kH=1。

先 C1=hypot(a1,b1)、C2=hypot(a2,b2)，Cb=(C1+C2)/2，G=0.5*(1-sqrt(Cb⁷/(Cb⁷+25⁷)))（Cb=0 时G=0.5）。a'i=(1+G)ai，C'i=hypot(a'i,bi)，h'i=atan2(bi,a'i) 的角度模360，无色度时0。

ΔL=L2-L1、ΔC=C'2-C'1。Δh=h'2-h'1；C'1*C'2=0 时0；大于180减360、小于-180加360。ΔH=2*sqrt(C'1*C'2)*sin(Δh/2)。Lbar=(L1+L2)/2、Cbar=(C'1+C'2)/2。hbar 在零色度时 h'1+h'2，在色相差<=180时普通平均；其余若两角和<360则(和+360)/2，否则(和-360)/2。

```text
T = 1 - 0.17*cos(hbar-30) + 0.24*cos(2*hbar)
      + 0.32*cos(3*hbar+6) - 0.20*cos(4*hbar-63)
SL = 1 + 0.015*(Lbar-50)^2/sqrt(20+(Lbar-50)^2)
SC = 1 + 0.045*Cbar
SH = 1 + 0.015*Cbar*T
RT = -2*sqrt(Cbar^7/(Cbar^7+25^7))
       *sin(60*exp(-((hbar-275)/25)^2))
DE = sqrt((DL/SL)^2 + (DC/SC)^2 + (DH/SH)^2
          + RT*(DC/SC)*(DH/SH))
```

括号中的 cos/sin 参数以上均表示角度，实际实现转弧度。原测试包括 Lab 往返中性检查，但没有完整的 CIEDE2000 标准样例组，不能把局部测试说成所有指标公式已被独立验证。

## 4. ColorChecker 实际聚合

要求24个框。每框内先计算**每个像素对的 ΔE2000，再求框内均值**，最后对有限值的框均值平均；不是先求色块平均 RGB 或 Lab 再算差。空框生成 NaN，而汇总忽略 NaN。当前 CLI 不要求24框全部有效，故部分空框仍可能得到 pass，验收方应核实 swatches 有24个有限值。

图尺寸不一致会记录 shape_mismatch，CLI 据此 fail。没有输入 ICC 适配；在 ColorChecker helper 中图像数值直接当 sRGB，因此 AdobeRGB 文件需先转换再使用。mean<2 才通过，等于2失败。

## 5. 颗粒统计实际含义

flat_region_stats 默认取整幅图而非检测平坦区域，亮度取 RGB 算术平均（不是加权 luminance），mean、variance 均以总体除数计算，power 是二阶矩。Pipeline 统计的是 grain 后整幅图，含图像本身纹理，不能自动解释成纯颗粒方差。

grain_spectrum 均匀抽样最大 n=32 的方形网格，使用 round 把采样映射到原图全范围；减去均值后直接二维 DFT，功率=real²+imag²。radius=sqrt(kx²+ky²)/max(1,sqrt(2)*n)，idx=min(bins-1,int(radius*bins))，每 bin 平均，默认8 bins。频率坐标没有折叠负频率、未 fftshift、未窗函数，也未按 n² 标准化；应原样重建这一诊断定义。

compare_stage_directories 从两侧 pipeline.json 读统计；方差误差=绝对差，频谱 RMSE 对共同的 min 长度计算。仅两个误差均精确为0时pass；缺数据unverified，其余有数值fail。没有声明容差，也没有要求两个频谱长度相同。

## 6. 目录验收报告

load_stage_directory 读取根目录 *.tif，文件 stem 作名字；不递归。pipeline.json 不存在/损坏时元信息为空。stage_domains 先 reference 后 candidate 合并，candidate 覆盖。汇总目标：lut_3d 的平均ΔE<1；output_icc（缺失时sharpen）的平均ΔE<2；resize_lanczos 的 PSNR>35；颗粒按上述精确统计一致性。缺对应指标时unverified。

目录汇总的 end_to_end 是整图像素平均，不是 ColorChecker24 结果；ColorChecker 命令单独运行。unexplained_residual_stages 只列缺失和尺寸错误，**不会列出所有数值非零残差**。stage_coverage 来自元信息，不能单独作为真正计算正确性的证明。

## 7. 历史记录与本次证据

历史 `reference_core_validation.json` 已复制为 historical_core_validation.json：XH2S PROVIA 2000 样本，平均最大通道误差0.0006180562，P95=0.0025950489，最大0.0179743480；平均ΔE2000=0.0384187483，P95=0.1562919863，最大1.5311062042。pipeline 中硬编码的验证元信息与此一致。

原旧分析文字含另一组通道误差0.000596/0.002446/0.017437；本交付以机器记录为准，不混合不同数字。历史记录没有随机 seed、输入列表或完整比较脚本，因此本次不能重新独立复算该历史测量，也不能扩展到其余47表或端到端。

本次 run_report.json 记录原有9个测试的结果、48表解析和原有 manifest hash 核对、独立工程的 wheel 打包/安装检查、复现示例结果与环境。baseline_pixels.json 为**当前实现基准**，不是独立参考真值。示例覆盖内置彩色/黑白/棕褐、缺表解析、encoded/linear cube、sigma、线性直入、AdobeRGB、RAF 预览及人工传感器链。人工传感器夹具验证算法组合，不证明真实 RAF 质量。
