# 颜色变换核心详解

## 入口与复现要点

规范入口 `hncs_codes(native_wb_rgb,cct,assets,intent,use_lut,stats,working_space,film_curve,raw_film_curve)`。输入已经过白平衡、跨相机映射与曝光，不再在函数内部乘 WB。运算 float64，输入量化与输出查表的两个边界必须严格保留。独立实现见 `tools/reference_color_core.py`，固定向量见 `work/hncs-phocus-audit/evidence/native_kernel_vectors.npz`。

工厂 profile 固定 sensor_key=0x616、colour_path_revision=2。asset NPZ 是可直接使用的完整数值规范，`docs/09` 给出键、尺寸和矩阵实际值。原工厂 plist 中矩阵/WB 原始编码 `x*.5+1` 已在生成资产时转换，运行时不能再转换一次。

## 1. 输入量化

拒绝 NaN/Inf。统计原始值<0 或>1 的样本数，然后 `p=rint(clip(rgb,0,1)×65535)`。NumPy rint 的半整数行为是就近偶数，不能替换成 floor(x+.5)。此时 p 仍 float64，但只含整数。提前裁剪是当前核的行为；负值和高光信息已经丢失，不能在后面用浮点 HDR 方式保留。

## 2. 色温节点插值

factory CCT 先 int，再限制 [2000,10000]。`lerp_table` 用 `searchsorted(temperatures,cct)−1` 并把段号限制到 0…N−2，局部 f=(cct−Ti)/(Ti+1−Ti)。颜色核心调用 clamp=False：整体 2000…10000 限制之后，若温度超出实际节点，会沿第一/最后一段外推，并非将每张表固定到最近节点。这个细节与 paired 的范围外固定行为不同。

camera_to_xyz 有四个温度节点；Std/Repro LUT 各有三个 WB 温度节点。两者均按 Kelvin 的 f 对整张数值表线性插值，不采用逆 Kelvin。不能把 DCP 或响应模型的规则直接用于这里。

## 3. RGB 到内部 YCbCr

令 C 为插值 camera_to_xyz，A 为 xyz_to_legacy_rgb，B 为 legacy_rgb_to_xyz，T 为 rgb_to_ycbcr，S 为所选 working_rgb_to_xyz（lstar）或 B（legacy）。

```text
M_in  = T×A×C                       # Standard
M_in  = 1.7×T×A×C                   # Reproduction 非 HDR
M_out = inverse(S)×B×inverse(T)
[Y,Cb,Cr] = M_in×p
q = [Cb/Y,Cr/Y]，Y>0；否则 q=0
```

Reproduction 的 1.7 是该模式的灵敏度增益，不是 WB 或全模式曝光。YCbCr 的坐标系由资产 T 定义，不能换成视频编码的 BT.601 公式。

## 4. LUT 的意义、坐标与查表

原 grid=[CbS,CbE,CrS,CrE,DivFactor]=[-20,84,-32,56,32]，宽 105、高 89。lut_std/lut_repro 各为三温度×89×105×2。每个像元保存映射后的绝对 `[Cb,Cr]` 坐标，不是差值，也不是 RGB 三维 LUT。

```text
pos = q×32−[CbS,CrS]
pos = clip(pos,[0,0],[CbE−CbS,CrE−CrS])
low=floor(pos); high=min(low+1,[width−1,height−1]); f=pos−low
mapped = (L00(1−fy)(1−fx)+L01 fy(1−fx)
          +L10(1−fy)fx+L11 fy fx)/32
```

数组访问 L[y,x]，第一坐标是 Cb→x，第二坐标是 Cr→y。先沿 y 再沿 x 的计算顺序见源码；为 uint16 精确结果尽量保留相同浮点顺序。边界 high=low 时同一像元重复参与插值，外部坐标夹到边界。

legacy 使用原表；lstar 先扩展 left=5,top=7,right=55,bottom=12，得到高108×宽165、新 grid=[−25,139,−39,68,32]。先左右后上下填充。左扩展的映射 Cb 从原最左值减 left…1；右从最右值加 1…right，另一个映射坐标保留边界值。上/下同理只线性延伸映射 Cr，另一坐标取最近边界；因此角点随填充顺序同时具有对应延伸。最终查表外部仍 clamp。

`--no-lut` 是诊断开关，让 mapped=q，其他矩阵、暗部和曲线照常；它不是另一个已标定的标准外观。

## 5. 低饱和与暗部权重

mean=mean(pRGB)，sat=max(abs(p−mean))/mean，mean≤0 时 sat=0。通用灰度权重为 clip((sat−lower)/(upper−lower),0,1)，但当前 X2D II 的 gray_thresholds=[0,0]，upper≤lower，所以 gray_weight 恒为 1。不能替换成通用 0.07/0.005 阈值，也不能强制 LUT 中性轴完全无色偏。

Standard 启用暗部去饱和。threshold t=15500，amount d=−.123，

```text
a=d/t²
b=−2a×t
c=a×t²+1
shadow(Y) = (aY)Y+bY+c，Y≤t；否则为1
weight=max(0,min(gray_weight,shadow(Y)))
```

因此 Y=0 时权重 .877，Y=t 时 1；这个公式使用 Y 的 16 位量级，不能输入 0…1 的 Y。Reproduction 跳过暗部去饱和，仅保留 gray_weight。单位有效增益是当前范围；其他原生曝光/局部 WB 增益分支没有通过这个公式完整表达。

## 6. 工作 RGB 与输出量化

每个通道 j：`z_j = Y + Y×weight×dot(M_out[j,1:3],mapped)`。它以 Y 作为共同中性基线，不是完整三通道 M_out×[Y,Cb,Cr]，不可把第一列矩阵再乘一次 Y。Y≤0 时 z 置零。

统计 z<0 或>65535 的数量；`index=clip(z,0,65535).astype(intp)`，非负浮点转整数是截断，不是 rint。`output=curve[index]`，curve 是 65536 项 uint16。保持输入 65535 尺度、建表 65536 分母和两次不同量化，才能通过固定向量逐像素比较。

## 7. 对接其他语言

建议每阶段保存 p、M_in、Y/q、插值 LUT、mapped、weight、z、index 和最终码，用固定 NPZ 中少量向量定位差异。矩阵使用 row-major 存储但列向量计算；末维 RGB；禁止 float32 代替主核 float64。边界测试至少含黑、负 RGB、高光越界、Y≤0、LUT 四边与扩展角、全部工厂节点及节点外 2000/10000 K、两意图两工作空间。

完整 LUT/曲线已附，移植可以直接读 NPZ 或将其无损导出为目标语言数组，不需要猜测常数。独立 reference 实现会对随包 52 组固定向量检查（6656 像素；历史原生随机测试为260000像素）；`validation/color_core_vectors.npz` 另保存容易使用的样例输入/输出。代码版本、资产和运行参数必须一起固定。
