# 曲线、预设与显示导出

## Film Curve 的选择规则

| CLI 名称 | type | legacy | lstar |
|---|---:|---|---|
| as-shot | 4 | 先解析 raw_film_curve，默认2 | 同左 |
| standard | 2 | v1_gamma | v1_lstar |
| low-contrast | 6 | v1_gamma | v1_lstar |
| high-contrast | 1 | v1_gamma | v1_lstar |
| old-standard | 0 | original_gamma | v1_lstar |
| linear | 7 | pure_gamma | pure_lstar |

Reproduction 无条件令 resolved_type=7。类型1…6在当前非 HDR 表选择中同属 V1；不能根据界面名称自行构造三条不同曲线。Linear 仍需要输出编码，不是直接把线性码写入 gamma/L* ICC。old-standard 在 lstar 也走 V1，这是代码明确的空间分支。

`original_gamma_curve` 用 i=0…65535、t=i/65536，v=65536×t^(1/4.1)，s=48/50。v<32768 时 d=s×(v²/32768−v)，否则 u=65536−v，d=s×u×(1−u/32768)。结果为 clip(65536×clip((v+d)/65536,0,1)^(1/.76),0,65535) 后截断 uint16。

V1 的已固定全表在 NPZ 内，保留全部量化值最容易获得相同结果。生成参考 `work/hncs-phocus-correction/evidence/v1curve.py` 按三段 gain、1025 项 UGradation 插值、gamma、自然三次样条以及可选 L* 尾部生成。其 UGradation 表来自版本固定的 HBUtil 数据，重新建表需挂载镜像；日常运行和其他语言移植直接用随包 65536 项表即可，表值本身是完整实现信息。

## 工厂预设与实际作用

完整 43 份 plist payload 在 `phocus_presets.json`，CLI 有更多别名，但底层来源文件数是43。顶层照片预设5、WB6、灰度4、锐化4、颗粒9，其余为工具设置。`docs/09` 列出每个文件的全部派生设置；原始 plist 始终随包。

render 的前置阶段处理裁切、CCT 和 native_tint_multiplier；颜色核心采用 CLI 的 `--film-curve`。`settings` 读取的 FilmCurve、EV、Brightness 不会自动全量接入：当前 apply_preset **没有**应用预设 EV/Brightness，且没有用 preset FilmCurve 覆盖 CLI 曲线。实现者必须遵循实际入口行为，不能见到字段就额外施加。镜头、除尘、透视、降噪、场景校准与调整层配置保存到 provenance，未执行完整对应内核。

颜色核心之后，仅 preset_key 不是 standard 时运行 RGB 预设。Standard 直接跳过此阶段，以保留原输出码。`apply_preset` 自身默认 apply_sharpness=false，但 CLI render 默认 true，两种调用不能混淆。

## RGB 预设运算顺序

uint16 工作码先转 float32/65535，之后依次执行：

1. 饱和度 s：mean 为三个通道算术平均，`work=mean+(work−mean)×(1+s/100)`；这是编码工作 RGB 上的操作，不是 HSV 或线性 XYZ。
2. 对比度 c：`work=(work−.5)×(1+c/100)+.5`。
3. Gradations 只读取列表的第一组 Points，XY 各除255；点数>2才应用，以 np.interp 对 clip(work,0,1) 逐通道线性插值。该便携实现没有采用厂商的样条。
4. ApplyGrayScale 且 GrayScale 非空：权重取数组[1:4]/100，灰度=sum(work×weights)，重复为三通道，没有重新归一化权重。
5. 颗粒。
6. 可选 USM。
7. clip 到[0,1]，rint×65535，转 uint16。

## 稳定颗粒算法

只有 ApplyFilmGrain 为真且 Amount 非零才执行。Amount/Color/Roughness/Size 均除100，Type转整数。种子取 SHA256 字符串 `preset_key:work.shape` 的前8字节，little-endian 整数，再 `np.random.default_rng(seed)`。因此同尺寸同预设的颗粒场固定；图像尺寸或别名的 key 改变可能改变颗粒。

初始二维标准正态噪声是 float32；fine_sigma=max(.15,.35+.8×size+.15×type)，coarse_sigma=max(.5,1.3+3×size+.35×type)。gaussian_filter 用 wrap 边界。grain_plane=(1−roughness)×fine+roughness×coarse，除 max(std,1e−6)。Color 非零时，R 用 grain_plane，G/B 用两次新正态噪声经 fine_sigma 平滑，分别按空间 std 标准化，然后与共享 grain_plane 以 color 混合。Color=0 则三通道用同一场。

strength=.012×amount×(.55+.45×sqrt(clip(work,0,1)))；输出 clip(work+channels×strength,0,1)。这是本项目明确定义的稳定便携模型，可在相同 NumPy/SciPy 算法版本下复现，不是厂商随机颗粒逐样本核验结果。

## USM 算法

amount=USMAmount/100，radius=max(USMRadius/10,.1)。对全图 RGB 用 gaussian_filter，sigma=(radius,radius,0)，mode=nearest；detail=work−blurred；若 NoiseLimit 非零，按 abs(detail)≥NoiseLimit/65535 保留，其他置零；输出 clip(work+amount×detail,0,1)。USMDarkLimit 只保存，没有用于运算。`--no-sharpness` 关闭该步骤，不关闭颗粒。

## 工作 RGB→sRGB

主 TIFF 内已含完整曲线外观。ICC 只描述输出编码与色度，不能用 inverse(V1) 恢复场景线性值。legacy 解码为 encoded^(563/256)，不是直接用2.2；lstar 解码为：encoded≤.08 时 encoded/(24389/2700)，否则 ((encoded+.16)/1.16)^3。

解码值乘对应 working_rgb_to_xyz，获得 XYZ。源白为该矩阵各行之和，目标为 [.95047,1,1.08883]；Bradford 矩阵 B=[[.8951,.2664,−.1614],[−.7502,1.7135,.0367],[.0389,−.0685,1.0296]]，CAT=inverse(B)×diag((B×white_target)/(B×white_source))×B。转换 XYZ 后乘固定 XYZ→sRGB 矩阵，clip[0,1]。sRGB OETF 在线性值≤.0031308时12.92×v，否则1.055×v^(1/2.4)−.055。转换会裁剪超出 sRGB 的颜色，没有额外感知色域映射。

sRGB TIFF 是 rint(encoded×65535)；JPG 从 uint16 用 `(value+128)//257` 得 uint8，quality98/subsampling0。预览先在**已编码工作码**中按面积平均，再转 sRGB，不是先对全图线性值平均，因此重建预览也需保持顺序。preview 最大参数1800通过 ceil 分组，有时输出最长边小于1800。

## 普通 DNG 与原色对照

DNG 不把 HNCS 写入传感器数据。导出 full raw_image，uint16 无压缩 CFA TIFF，DNGVersion1.4、兼容1.1；两个绿色索引合为CFA颜色1，black 按2×2 CFA记录，white 取正的 per-channel whites 最小值（若无则 raw.white_level）。ColorMatrix1取 LibRaw XYZ→camera 矩阵，用百万分母 SRATIONAL；AsShotNeutral=wbG/wb，每亿分母 RATIONAL，CalibrationIlluminant1=D65。

同时保存 ActiveArea、DefaultCropOrigin/Size、Orientation、Make/Model/UniqueCameraModel、原文件名和可用普通拍摄/镜头元数据。Sony 私有 MakerNotes 没有迁移。写出后实际重读：full CFA和visible CFA均逐样本相同，WB相对误差<1e−6，相机矩阵误差<1e−6，方向相同。

原色图从该 DNG 重新显影，采用 AHD、拍摄WB、相机矩阵、sRGB gamma=(2.4,12.92)、无自动提亮、无FBDD/median。与直接 ARW 常规显影分别比较最大/平均/P99码差。CFA相同不保证容器变化后 LibRaw 所有后续像素相同；保存的误差记录已有少量非零值。

Orientation8旋转90°逆时针，6旋转90°顺时针，3旋转180°；TIFF保留方向标签，JPG实际旋转。所有图片哈希、尺寸、WB、光源权重和模型哈希写入旁路 JSON。
